A QUICK GUIDE

Make room for the details.

  1. Start with a storefront link

    Paste one or many public store, collection or product URLs, one per line. Shopify, WooCommerce and Fynd use product data endpoints; custom stores use structured data, page links and a browser fallback.

  2. Explore what you collected

    Open a collection to search products, compare prices and view the original image gallery. Your existing CSV files are already available in the library.

  3. Take the data with you

    Download a combined CSV from a completed batch or export individual collections. A separate run report lists failed links and partial results. Image URLs are included; image files are not downloaded.

Jobs and collections are saved on this computer. Unfinished links are retried after a server restart. There is no lifetime link quota. 0 means no page limit, but site restrictions and computer resources still apply. Login walls, CAPTCHAs and some custom layouts cannot be collected automatically.
